# 🚀 GenMarket: Autonomous AI Prediction & Dispute Resolution Market

GenMarket is a decentralized prediction market platform natively running on GenLayer's GenVM. By combining AI-driven execution (`gl.exec_prompt`) with multi-validator consensus, GenMarket dynamically fetches real-world off-chain data, resolves prediction market outcomes, and processes disputes autonomously without human intervention or centralized oracles.

### ✨ Key Features
- **AI-Powered Resolution:** Automatically verifies prediction outcomes using web data via GenLayer AI consensus.
- **On-Chain Dispute Mechanism:** Allows transparent re-evaluation of contested market decisions through decentralized validator AI consensus.
- **Automated Payout Engine:** Proportional reward distribution based on user bets.
- **Strict State Security:** Guarantees single-claim logic and resilient consensus state handling.
# GenMarket: Autonomous AI Prediction & Dispute Resolution Platform

GenMarket is a next-generation decentralized prediction market powered by GenLayer's GenVM. It leverages AI-driven web consensus to fetch real-world data, evaluate outcomes, and autonomously handle dispute resolution without human bias or centralized oracle reliance.

## Features

- **Decentralized AI Oracles**: Uses GenLayer AI execution (`gl.exec_prompt`) to read web evidence and determine market outcomes.
- **Consensus-Driven Dispute Engine**: Enables transparent appeal/dispute resolution re-assessed by multi-validator AI consensus.
- **Automated Payout Pool**: Mathematical proportional payout pool distribution for winning participants.
- **Strict State Security**: Prevents double-claiming and handles invalid consensus edge cases.
